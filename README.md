# Euro Transit Guide

Public transport guides for European capitals, for tourists. It has an interactive map of Europe and a page per capital covering train, tram and metro, bus and airport links. Each page shows schedules, train destinations, where to buy tickets, ticket prices, the metro network, tips, apps and live transport news.

## Project layout

```
site/                 What gets published
  index.html
  css/styles.css
  js/app.js           Map, routing and country pages
  sw.js               Offline cache (pages you have opened keep working)
  data/               Generated by the build (do not edit by hand)
data/
  countries/XXX.json  One file per country: edit these to change content
  general-tips.json   Tips shown on every city page
  routes/             Route hub guides, such as london-paris.json
  affiliates.json     Booking partner links (empty = hidden)
netlify/functions/news/news.mjs   Live news API at /api/news?country=FRA
scripts/build.mjs     Bundles data, downloads the map
scripts/dev.mjs       Local preview with the news API
scripts/test.mjs      Data and parser checks
netlify.toml          Netlify settings
```

No npm packages are needed. You only need Node 18 or newer.

## Run it locally

```
npm run dev      # builds, then serves http://localhost:8888
npm test         # checks data files and the news parser
npm run audit    # lists data that disagrees between pages, thin lists and old checks
```

The first build downloads the Europe map (world-atlas, Natural Earth 1:50m) into `site/data/world.topo.json`. If that download fails, the site falls back to a map loaded from cdnjs.

## Legal pages

The build writes `/privacy/` and `/affiliate-disclosure/`. Set `CONTACT_EMAIL` in Netlify environment variables (next to `SITE_URL`) to show a contact address on them; without it the contact line is left out.

## Deploy to Netlify

Netlify Drop (drag and drop) does not run functions, so deploy from Git or with the CLI so that live news works.

**From GitHub (recommended)**
1. Create a GitHub repository and push this folder to it.
2. In Netlify, choose Add new site, then Import an existing project, then pick the repository.
3. Netlify reads `netlify.toml`, so you don't need to change any settings. Click Deploy.
4. Optional: under Domain management, add your own domain.

**With the Netlify CLI**
```
npx netlify-cli login
npx netlify-cli deploy --build --prod
```

## Common updates

**Change a fare or text:** edit `data/countries/XXX.json`, update `verified` to the date you checked it, and add the page you checked to `sources`.

**Add a country:** copy an existing file in `data/countries/`. Rename it to the ISO 3-letter code, then set these fields:
- `id`: the same 3-letter code
- `isoNumeric`: the ISO numeric code, used to find the shape on the map
- `flag`: a colour spec, `h:` for horizontal stripes or `v:` for vertical, e.g. `"h:#ffffff,#dc143c"`
- `lonLat`: the capital's longitude and latitude

The build adds it to the map, the list and the news API.

**Turn on booking links:** join the affiliate programmes (for example Trainline, Omio, FlixBus, Skyscanner). Paste each tracking link into `data/affiliates.json`, either as `link` for every city or in `cityLinks` under a country code. Partners with no link stay hidden. The disclosure text appears in the footer as soon as one link is set.

**News source:** the function searches the Google News RSS feed for transport headlines about each capital from the last 7 days. Results are cached for 15 minutes. To use operator feeds instead, change `feedUrl` in `netlify/functions/news/news.mjs`.

## Route guides

A route guide is a long page for one popular journey, such as London to Paris. It is linked from the home page, from both capitals' pages, and from the matching row in the train destinations table.

To add one, copy `data/routes/london-paris.json`, rename it, and change `id` (it must match the file name), `from`, `to`, `stats`, `official`, `sections`, `options`, `faq` and `sources`. Section blocks can be `p`, `table`, `list`, `steps` or `tip`. Run `npm test` to check it.

Partner buttons on a route page (Trainline, Omio, Interrail seat reservations, Airalo eSIM) are set in `data/affiliates.json` under `routes`. Paste your tracking link into `link`. A slot with no link stays hidden.

## Search engines and sharing

The build writes a real page for every capital (`/paris/`) and route guide (`/routes/london-paris/`), each with its own title, description, canonical link and (for routes) FAQ structured data. It also writes `sitemap.xml` and `robots.txt`. These files are generated, so don't edit them.

Set your real address before you deploy: in Netlify, go to Site configuration, then Environment variables, and add `SITE_URL` (for example `https://yoursite.com`). Without it the build uses Netlify's own `URL` value, and locally it uses `https://example.com`. After the first deploy, submit `/sitemap.xml` in Google Search Console.

## Other features

- **Checked dates** show next to each city and route so visitors can see how fresh the prices are.
- **Copy trip summary** copies a plain-text card; **Print or save as PDF** shows on the live site and prints a clean page.
- **Offline use:** after a first visit, pages and data keep working without a connection. Live news needs a connection.
- **City pass and eSIM buttons** appear on the Tram & Metro and Tips & Apps tabs as soon as you set a link for them in `data/affiliates.json`.

## Logo, icons and share image

The header uses the pastel logo (colours `--logo-rose`, `--logo-sky`, `--logo-mint` in `css/styles.css`). `site/favicon.svg` is the browser tab icon, `site/apple-touch-icon.png` the phone home-screen icon, and `site/og-image.png` (1200 by 630) the picture shown when someone shares a link on social media or a chat app. To change the share image, replace that file. The build writes the matching tags between the `seo:start` and `seo:end` markers in `site/index.html`, so leave those markers in place.
